ويز اليوسفية — النسخة التأسيسية لتجربة المنصة اليومية

الهدف العام:
تحويل ويز اليوسفية من دليل أماكن فقط إلى منصة محلية يومية تجمع المجتمع المحلي والدليل والخدمات وطلبات المستخدمين، مع إبقاء التصفح العام مفتوحاً للجميع واشتراط الحساب للطلبات والتفاعل والإجراءات الشخصية.

ما أُنجز في هذه النسخة (المرحلة التأسيسية — تجربة الدخول اليومية):
- إضافة «بوابة ويز اليومية» إلى الصفحة الرئيسية كمدخل واضح للأقسام الأساسية.
- اختصارات مباشرة إلى نبض اليوسفية، اكتشاف الأماكن، طلب خدمة، ومساحة المشروع.
- رسالة ترحيب تتغير حسب الوقت، وتعرض الاسم الأول عند تسجيل الدخول.
- توضيح أن التصفح متاح للجميع، بينما الحساب مطلوب للطلبات والتفاعل.
- تحديث وصف هوية المنصة في الترويسة من دليل وخريطة فقط إلى مجتمع وخدمات وحياة يومية.
- تحديث نسخة Service Worker حتى تصل تغييرات الواجهة للمستخدمين بعد النشر.

الموجود مسبقاً ويستمر بالعمل:
- الدليل والبحث والخريطة والتصفية.
- نبض اليوسفية مع تصنيف المنشورات وألوان الخبر/التنبيه/العرض.
- طلبات الخدمات ومتابعتها وتوجيهها من الإدارة حسب نسخة المرحلة الرابعة.
- إدارة المشاريع والتقييمات ولوحة الإدارة.

مهم:
- هذه بداية إعادة تنظيم تجربة المنصة وليست ادعاءً بأن جميع الأنظمة المستقبلية اكتملت.
- لم يتم اختبار اتصال Supabase الحي أو إجراء نشر فعلي في هذه الخطوة.
- لم تتغير قاعدة البيانات في هذه المرحلة، لذلك لا تحتاج Migration جديدة بسبب بوابة ويز اليومية.
- لا تستبدل إعدادات Supabase أو مفاتيح المشروع الموجودة في app.js.

التحقق المنفذ:
- node --check على app.js.
- تحليل HTML الأساسي بنجاح.
- يلزم اختبار التصفح وتسجيل الدخول والطلبات على النسخة المنشورة قبل اعتمادها نهائياً.
