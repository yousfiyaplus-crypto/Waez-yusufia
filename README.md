ويز اليوسفية - تحديث المرحلة الثالثة: نبض اليوسفية

هذه نسخة المشروع الكاملة مبنية على حزمة التطوير السابقة، مع تحسينات إضافية لقسم نبض اليوسفية:
- فلاتر للأخبار والتنبيهات والعروض.
- زر تحديث يدوي للتحديثات المحلية.
- حالة فارغة واضحة عند عدم وجود منشورات في التصنيف المحدد.
- إظهار تنبيه قرب انتهاء المنشور عندما يكون موعد الانتهاء خلال يوم.
- الحفاظ على صلاحيات النشر للإدارة فقط كما هي في قاعدة البيانات.

قاعدة البيانات:
- جدول community_posts وسياسات RLS موجودة في stage3-4-migration.sql من الحزمة السابقة.
- إذا لم تكن قد نفذت ملف SQL سابقاً، نفّذه مرة واحدة في Supabase SQL Editor.
- إذا كنت قد نفذته بنجاح سابقاً، لا حاجة لإعادة تنفيذه لهذا التحديث.

المرحلة الرابعة (طلبات الخدمات) ما زالت موجودة في هذه الحزمة السابقة، ولم تُجرَ عليها تغييرات في هذا التحديث.

الاختبارات المنفذة: node --check لملف app.js، وتحليل HTML الأساسي. لم يتم الاتصال بمشروع Supabase الحي أو اختبار النشر الفعلي.
