ويز اليوسفية - نسخة تطوير المراحل 2 إلى 5

محتويات النسخة:
- index.html: الواجهة الرئيسية والصفحات.
- app.js: منطق التطبيق والاتصال بـ Supabase.
- sw.js: Service Worker مع تخزين غلاف التطبيق فقط دون تخزين بيانات Supabase.
- manifest.json: إعدادات تثبيت PWA.
- stage3-4-migration.sql: إنشاء جداول نبض اليوسفية وطلبات الخدمات وسياسات RLS.

خطوات التفعيل:
1) ارفع ملفات الواجهة إلى الاستضافة مع الحفاظ على المسارات.
2) افتح Supabase > SQL Editor.
3) نفّذ محتوى stage3-4-migration.sql مرة واحدة.
4) تأكد أن حساب الإدارة يحمل profiles.role = 'admin'.
5) اختبر النشر من لوحة الإدارة، ثم جرّب إرسال طلب خدمة من حساب مستخدم عادي.

ملاحظات:
- لم يتم تغيير بيانات الجداول الحالية shops/categories/profiles/reviews.
- ميزتا نبض اليوسفية وطلبات الخدمات تحتاجان تنفيذ ملف SQL حتى تعملان فعلياً.
- لم يتم إجراء اختبار حي على Supabase أو على الاستضافة؛ الاختبارات المنفذة هنا فحوصات صياغة JavaScript ومراجعة بنية HTML.
- أُضيف رمز مؤقت للتطبيق بصيغتي 192 و512 بكسل حتى تعمل أيقونات PWA؛ يمكن استبداله لاحقاً بالشعار الرسمي المعتمد.
